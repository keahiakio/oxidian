# Security Policy

## Supported Versions

Only the latest commit on the `master` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `master`| :white_check_mark: |
| < `master`| :x:              |

## Reporting a Vulnerability

If you discover a security vulnerability in `oxidian`, please report it responsibly:

1. **GitHub Private Vulnerability Reporting**: Use GitHub's private vulnerability reporting feature under the **Security** tab of the repository if available.
2. **Direct Contact**: If private reporting is unavailable, email [keahiakio@users.noreply.github.com](mailto:keahiakio@users.noreply.github.com) with the subject `[SECURITY] oxidian Vulnerability Report`.

Please include:
- A description of the issue and potential impact (e.g. arbitrary file traversal, shell injection in editor launch).
- Minimal steps or proof of concept to reproduce.
- Remediation suggestions if known.

### Response Timeline
- We will acknowledge receipt of your report within 48 to 72 hours.
- We will coordinate patch development and release before public disclosure.
- Please do not open public issues or disclose details publicly until a fix has been published.
